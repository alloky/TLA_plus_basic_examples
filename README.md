# Базовые примеры TLA+/PlusCal

Репозиторий содержит минимальные спецификации на языке PlusCal (псевдокод, компилируемый в TLA+), демонстрирующие ключевые концепции формальной верификации распределённых систем: детекция deadlock'ов, их устранение и моделирование консенсус-протокола Paxos. Примеры предназначены для быстрого старта с TLA+ Toolbox и понимания, как модельный чекер исследует граф состояний.
